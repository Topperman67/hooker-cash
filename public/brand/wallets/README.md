Other installed wallets can supply their own image data URI through [EIP-6963](https://eips.ethereum.org/EIPS/eip-6963). These are rendered as images, never inline SVG markup. The generic Browser wallet entry uses provider branding when identifiable; unknown providers and failed images fall back to a neutral wallet symbol. Logos identify an option visually and do not establish trust or determine provider capabilities.
