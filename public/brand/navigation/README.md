# Hookbrew navigation glass symbols

Generated individually with the built-in image tool using `../hookbrew/hookbrew-icon.png` as the visual style reference. Original generated PNGs are preserved with their transparency. These now identify navigation sections; they are not coin logos. The prompts below are the unchanged generation history from the previous design iteration.

## Shared direction

Use case: logo-brand. Create one square transparent PNG emblem for a fictional demo token in the Hookbrew app. The supplied Hookbrew flask is a STYLE REFERENCE ONLY: match its polished sculptural liquid-glass material, icy rim highlights, electric mint #a5e7d2 and ice blue #b9edff interior, restrained lavender #b4a1ff refraction. Replace the flask entirely with the requested subject. One bold simple centered silhouette that reads at 32–48 pixels; generous clear negative space; about 80% canvas occupancy. Softly rounded thick glass geometry, front or slight three-quarter view, consistent studio lighting. Actual transparent alpha background, no floor, no solid black or white backdrop, no frame or badge, no wordmark, no text, no letters, no logos from other brands, no watermark, no complex decoration. Designed for near-black purple #090411.
